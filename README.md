# Lembar: website dan unduhan

**Lembar** adalah alat PDF freeware untuk Windows. Lembar menggabung, mengurutkan, dan memutar halaman PDF
dan foto, lalu menyimpannya di bawah ukuran yang Anda tentukan, misalnya 800 KB untuk ijazah CPNS. Semua
diproses di komputer Anda, tanpa unggah.

- Website: https://romyrudiansah.github.io/lembar/
- Unduh installer: https://romyrudiansah.github.io/lembar/#unduh
- **Diskusi, tanya jawab, ide, laporan masalah:** tab [Discussions](https://github.com/romyrudiansah/lembar/discussions)
- Kebijakan privasi: https://romyrudiansah.github.io/lembar/privacy.html

Repo ini hanya berisi hasil build website, dan installernya ada di
[Releases](https://github.com/romyrudiansah/lembar/releases). Lembar adalah freeware dan kode sumbernya tidak
publik. Lisensinya ada di [LICENSE.txt](LICENSE.txt), dan komponen pihak ketiga ada di
[THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt). Isi repo ini ditimpa setiap rilis.

---

**Lembar** is a freeware PDF tool for Windows: merge, reorder, and rotate PDF pages and photos, then save
them under a size you choose. This repository only holds the built website, and the installer is under
[Releases](https://github.com/romyrudiansah/lembar/releases). Lembar's own source code is not public;
third-party components are listed in [THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt). Questions, ideas,
and bug reports go to [Discussions](https://github.com/romyrudiansah/lembar/discussions).
